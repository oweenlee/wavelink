Support & FAQ

Last updated: August 19, 2026

Tips, troubleshooting, and answers to common questions about WaveLink. Can't find what you're looking for? Email us and we'll get back to you within 48 hours.

1Getting Started

  • Supported formats: FLAC, ALAC, WAV, AIFF, DSD (DSF/DFF), APE, MP3, AAC, and Ogg Vorbis. Lossless and hi-res files are played at their native sample rate and bit depth with no conversion.
  • Scanning local music: WaveLink scans selected folders on your device, reading embedded metadata and cover art automatically.
  • Importing from Apple Music / iTunes: With your permission, WaveLink can import tracks from your Apple Music library. Access is used only for importing and can be revoked anytime in system settings.
  • Playback queue: Tap any track to play it; "Play Next" and "Play Later" let you build a queue on the fly.

2HiFi Output

  • Native sample rate switching: WaveLink negotiates the output stream at the file's native sample rate (e.g. a 44.1 kHz FLAC plays at 44.1 kHz, a DSD64 file at 2.8224 MHz). No resampling — what you hear is what's on the disc.
  • Exclusive mode: On Android, WaveLink first attempts MMAP exclusive output and automatically falls back to shared mode if the device doesn't support it. On Windows desktop, WASAPI exclusive mode can be enabled in settings.
  • USB DAC: When a USB DAC is connected, audio is routed to it automatically. WaveLink attempts native exclusive output on the DAC. If the DAC isn't detected, see Troubleshooting below.
  • Volume: Digital volume is applied in 32-bit float processing, so lowering the volume doesn't sacrifice bit depth.
  • Room correction: Import FIR filter files (e.g. measured with REW) to apply convolution-based room correction and EQ — a pro feature unique to WaveLink.

3NAS & WebDAV

  • Adding a server: Go to Settings → Library → Add Server, enter the address and your credentials. Credentials are stored only on your device (or in the system keychain) and are never transmitted to us or any third party.
  • Supported protocols: SMB and WebDAV (including HTTPS). Use WebDAV over HTTPS for encrypted transfers.
  • Offline playback: Download tracks from your server to play back offline without any DRM or lock-in.

4Troubleshooting

No sound is playing

Check the system output device and volume first. If you're using a USB DAC, make sure it's selected as the system output. On Windows, try disabling WASAPI exclusive mode, then re-enabling it after the track starts. If the file is DSD, confirm DSD passthrough is supported by your DAC, otherwise WaveLink converts DSD to PCM automatically.

Popping or stutter when switching tracks

This usually happens at the moment the audio stream is rebuilt for a new sample rate. If it's frequent, check that the device isn't overloaded (high CPU, other apps). On shared (non-exclusive) mode, system sounds or other apps can briefly interrupt playback — enabling exclusive mode where available reduces this.

My USB DAC isn't detected

Replug the DAC, try a different cable or port, and make sure it's powered (some DACs need external power). On Android, grant USB permission when prompted and check Settings → USB Output. Restart the app — the audio engine re-enumerates output devices on launch.

NAS / WebDAV server won't connect

Verify the address, port, and credentials. Check that the server is reachable from the same network (try its web interface from your phone/computer). If the server only allows one connection, close other clients. For WebDAV, ensure the server supports the protocol version WaveLink uses; HTTPS URLs require a valid certificate.

Music is missing from my library

Run a rescan (Settings → Library → Rescan). Files downloaded from some stores may be DRM-protected and cannot be read by third-party players. If a track is corrupt, the scanner skips it — check the file plays in another player and re-add it.

Battery drains faster during playback

Hi-res playback at native sample rates uses more CPU. Keep the screen brightness low and avoid other heavy apps while listening. On Android, exclusive mode can be more efficient than shared mode on supported devices.
