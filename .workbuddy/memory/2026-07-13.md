## NowPlayingBar 切歌闪动修复
- **问题**: 列表页切歌时，底部播放横条闪动、由小变大
- **根因**: `{#key}` + `transition:fade` 导致 DOM 销毁重建时，新旧元素同时存在于 flex 布局中，挤开相邻元素
- **修复**: 去掉 `{#key}` 包裹和 `transition:fade`，保持 DOM 结构稳定。封面图已有 CSS `transition: background-image 0.4s` 提供平滑过渡
