## NowPlayingView 完全重写 — 纯 CSS + 无 svelte-motion 依赖

### 根因确认
- 最小化版本（纯 HTML + "NOW PLAYING — DEBUG"）能打开 → 确认问题在 svelte-motion 运行时
- motion.div initial/animate 在 Tauri WebView 中 opacity 停在 0，元素渲染但不可见

### 重写方案
- 彻底移除 @humanspeak/svelte-motion 依赖（AnimatePresence、motion.div 等全部删除）
- 根元素: 普通 div + CSS `@keyframes npFadeIn`
- 封面入场: CSS `@keyframes npCoverIn`
- 切歌 meta: Svelte `{#key playback.currentTrack?.id}` + CSS `@keyframes npMetaIn`
- 信息面板: Svelte 内置 `transition:fly`
- 按钮: CSS `:hover` / `:active`

### 同时修复
- `playlist.tracks` → `playlist.queue`（playlist store 的正确 API）
- `playlist.shuffle` / `playlist.loop` / `toggleShuffle` / `toggleLoop`（不存在） → `playback.playMode` + `playback.cyclePlayMode()`
- 两个播放模式按钮合并为一个 cyclePlayMode 按钮（与 NowPlayingBar 一致）
- 构建通过，零错误

### 修复进度条不显示 + "下一首"移至左下角
- **进度条不显示根因**: NowPlayingView 给 ProgressBar 传了 `currentTime` 但没传 `value`。ProgressBar 用 `value` 算 `fillPct`，`value` 是 `undefined` → `fillPct` 始终 0%
- **修复**: 加 `value={playback.currentTime}`
- **"下一首"位置**: 从 `.np-main` 流式布局中移出，改为 `.np` 根的 `position:absolute; bottom:20px; left:24px`
- **样式**: opacity 0.35、10-11px 字体、fg-tertiary 色、hover 时 opacity 0.6，纯轻提醒
