技术支持与常见问题

最后更新：2026年8月19日

关于 WaveLink 的使用技巧、故障排查与常见问题。没找到你想要的答案？给我们发邮件，我们会在 48 小时内回复。

一快速上手

  • 支持的格式：FLAC、ALAC、WAV、AIFF、DSD（DSF/DFF）、APE、MP3、AAC、Ogg Vorbis。无损与高解析文件以原始采样率、位深直接播放，不做任何转换。
  • 扫描本地音乐：WaveLink 扫描设备上您选择的文件夹，自动读取内嵌元数据和封面。
  • 从 Apple Music / iTunes 导入：在您的授权下，WaveLink 可以导入 Apple Music 资料库中的曲目。该权限仅用于导入，可随时在系统设置中撤销。
  • 播放队列：点击任意曲目即可播放；"接下来播放"和"稍后播放"让你随时构建队列。

二HiFi 输出设置

  • 原生采样率切换：WaveLink 按文件的原始采样率协商输出流（例如 44.1 kHz 的 FLAC 就以 44.1 kHz 播放，DSD64 以 2.8224 MHz 播放），不重采样——听到的就是碟片上的原声。
  • 独占模式：Android 上 WaveLink 会优先尝试 MMAP 独占输出，设备不支持时自动回退到共享模式；Windows 桌面端可在设置中开启 WASAPI 独占模式。
  • USB DAC：接入 USB DAC 后音频自动路由到 DAC 输出，并优先尝试原生独占输出。如果 DAC 未被识别，请参阅下方"故障排查"。
  • 音量：数字音量在 32 位浮点处理中完成，调低音量不会损失位深。
  • 房间校正：可导入 FIR 滤波器文件（如用 REW 测量生成），进行卷积房间校正与均衡——这是 WaveLink 独有的专业功能。

三NAS 与 WebDAV

  • 添加服务器：前往 设置 → 音乐库 → 添加服务器，输入地址和凭据。凭据仅保存在您的设备上（或系统钥匙串中），绝不会传输给我们或任何第三方。
  • 支持的协议：SMB 与 WebDAV（含 HTTPS）。需要加密传输时请使用 HTTPS 的 WebDAV。
  • 离线播放：可将服务器上的曲目下载到本地离线播放，无任何 DRM 或锁定限制。

四故障排查

播放没有声音

先检查系统输出设备和音量。如果使用 USB DAC，确认它已被选为系统输出。Windows 上可尝试先关闭 WASAPI 独占模式，等歌曲开始播放后再重新开启。若是 DSD 文件，请确认 DAC 支持 DSD 直通，否则 WaveLink 会自动将 DSD 转换为 PCM 播放。

切换歌曲时有爆音或卡顿

这通常发生在为新采样率重建音频流的那一刻。如果频繁出现，检查设备是否负载过高（CPU 占用高、其他应用并行）。共享模式下，系统提示音或其他应用可能短暂打断播放——在可用时开启独占模式可以减少这类干扰。

USB DAC 无法被识别

重新插拔 DAC，换一根线或换个接口，并确认供电正常（部分 DAC 需要外部供电）。Android 上请在弹出的提示中授予 USB 权限，并检查 设置 → USB 输出。重启应用——音频引擎会在启动时重新枚举输出设备。

NAS / WebDAV 服务器连不上

检查地址、端口和凭据是否正确。确认服务器与手机/电脑在同一网络可达（可用浏览器访问其网页界面测试）。若服务器只允许单连接，请先关闭其他客户端。WebDAV 请确认服务器支持的协议版本与 WaveLink 兼容；HTTPS 地址需要有效证书。

音乐库里缺少某些曲目

执行一次重新扫描（设置 → 音乐库 → 重新扫描）。部分商店下载的文件带有 DRM 保护，第三方播放器无法读取。如果文件损坏，扫描器会跳过——请确认该文件在其他播放器中可播后重新添加。

播放时耗电变快

高解析音乐以原生采样率播放会占用更多 CPU。听歌时请降低屏幕亮度，避免同时运行其他重型应用。Android 上，支持独占模式的设备使用独占模式通常比共享模式更省电。
